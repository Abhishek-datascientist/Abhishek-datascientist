🎯 ANSWER: The Android app icon is configured in TWO places:

1️⃣  MANIFEST CONFIGURATION (Tells Android which icons to use)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   📄 FILE: android/app/src/main/AndroidManifest.xml
   
   LINES 6-7:
   ┌──────────────────────────────────────────────────────┐
   │ <application                                         │
   │     android:icon="@mipmap/ic_launcher"               │
   │     android:roundIcon="@mipmap/ic_launcher_round"    │
   │     ...                                              │
   └──────────────────────────────────────────────────────┘
   
   WHAT THIS MEANS:
   • @mipmap/ic_launcher → Use the square icon
   • @mipmap/ic_launcher_round → Use the rounded icon

3️⃣  HOW ANDROID SELECTS THE RIGHT ICON
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   When app starts, Android checks device:
   
   ┌──────────────────────────────┐
   │ Is device Android 8.0+?      │
   └─────────┬────────────────────┘
             │
        YES  │     NO
             │
    ┌────────▼────────┐         ┌─────────────────┐
    │ Use Adaptive     │         │ Use Static Icon │
    │ Icon from        │         │ from mipmap-    │
    │ mipmap-anydpi-   │         │ [density]/      │
    │ v26/             │         │                 │
    │                  │         │ Check device    │
    │ Apply system     │         │ DPI:            │
    │ shape + colors   │         │                 │
    └──────────────────┘         │ 640 dpi (high)  │
                                 │ → mipmap-xxxhdpi│
                                 │                 │
                                 │ 480 dpi         │
                                 │ → mipmap-xxhdpi │
                                 │                 │
                                 │ 320 dpi         │
                                 │ → mipmap-xhdpi  │
                                 │                 │
                                 │ 240 dpi         │
                                 │ → mipmap-hdpi   │
                                 │                 │
                                 │ 160 dpi (low)   │
                                 │ → mipmap-mdpi   │
                                 └─────────────────┘


4️⃣  ADAPTIVE ICON CONFIGURATION (Android 8+)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

   📄 FILE: mipmap-anydpi-v26/ic_launcher.xml
   
   CONTENT:
   ┌────────────────────────────────────────────────┐
   │ <?xml version="1.0" encoding="utf-8"?>         │
   │ <adaptive-icon                                 │
   │   xmlns:android="http://schemas.android.com... │
   │   >                                            │
   │   <background                                  │
   │     android:drawable=                          │
   │     "@color/ic_launcher_background"/>          │
   │                                                │
   │   <foreground                                  │
   │     android:drawable=                          │
   │     "@mipmap/ic_launcher_foreground"/>         │
   │ </adaptive-icon>                               │
   └────────────────────────────────────────────────┘
   
   USES:
   • ic_launcher_foreground.png (the icon image)
   • @color/ic_launcher_background (white #FFFFFF)
   
   BACKGROUND COLOR:
   ┌────────────────────────────────────────────────┐
   │ FILE: values/ic_launcher_background.xml        │
   │                                                │
   │ <resources>                                    │
   │   <color name="ic_launcher_background">       │
   │     #FFFFFF                                    │
   │   </color>                                     │
   │ </resources>                                   │
   └────────────────────────────────────────────────┘

The Android app icon is configured in:

1. AndroidManifest.xml
   └─ Tells Android which icon files to use

2. mipmap-*/ directories  
   └─ Contains the actual PNG icon files
   └─ Organized by device screen density
   └─ 5 different DPI densities covered

3. mipmap-anydpi-v26/
   └─ Special adaptive icon for Android 8+
   └─ Uses XML + foreground image + background color

4. values/ic_launcher_background.xml
   └─ Defines background color (#FFFFFF) for adaptive icons

Result: The icon automatically scales and adapts to any Android device!
