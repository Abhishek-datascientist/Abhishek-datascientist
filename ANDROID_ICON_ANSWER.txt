✅ SHORT ANSWER:

The Android app icon is configured in TWO main places:

1. Configuration File: android/app/src/main/AndroidManifest.xml
   └─ Lines 6-7 tell Android which icon files to use
   
2. Icon Files Directory: android/app/src/main/res/
   └─ Contains all the actual icon PNG files organized by screen density


═══════════════════════════════════════════════════════════════════════════════


🔍 DETAILED LOCATIONS:

1. CONFIGURATION (tells Android what icons to use):

   📄 android/app/src/main/AndroidManifest.xml
   
   Lines 6-7:
   
   ```xml
   <application
       android:icon="@mipmap/ic_launcher"
       android:roundIcon="@mipmap/ic_launcher_round"
   >
   ```
   
   This tells Android:
   • Regular icon: @mipmap/ic_launcher
   • Rounded icon: @mipmap/ic_launcher_round
   • Location: Look in mipmap-* directories


2. ICON FILES (the actual images):

   All located in: android/app/src/main/res/
   
   ✓ mipmap-mdpi/           (160 dpi - 48×48 pixels) - Small phones
   ✓ mipmap-hdpi/           (240 dpi - 72×72 pixels) - Old tablets
   ✓ mipmap-xhdpi/          (320 dpi - 96×96 pixels) - Medium phones
   ✓ mipmap-xxhdpi/         (480 dpi - 144×144 pixels) - Large phones
   ✓ mipmap-xxxhdpi/        (640 dpi - 192×192 pixels) - Large tablets
   ✓ mipmap-anydpi-v26/     (Adaptive icon for Android 8.0+)
   
   
3. ICON FILES IN EACH DIRECTORY:

   Each mipmap-* folder contains 3 files:
   
   ├─ ic_launcher.png              (square icon)
   ├─ ic_launcher_round.png        (rounded icon)
   └─ ic_launcher_foreground.png   (for Android 8+ adaptive icons)
   
   Total: 5 DPI folders × 3 files = 15 files
   Plus: 2 XML files in mipmap-anydpi-v26/
   Plus: 1 color definition in values/
   Total: 18 icon-related files


4. ADAPTIVE ICON SUPPORT (Android 8.0+):

   📄 mipmap-anydpi-v26/ic_launcher.xml
   
   This file tells Android to use:
   • Foreground image: ic_launcher_foreground.png
   • Background color: @color/ic_launcher_background
   
   📄 values/ic_launcher_background.xml
   
   Defines the background color: #FFFFFF (white)

🎨 HOW IT WORKS:

When user installs PocketTracker:

Step 1: Android reads AndroidManifest.xml
   ├─ Sees: icon="@mipmap/ic_launcher"
   └─ Understands: "Look for ic_launcher files in mipmap folders"

Step 2: Android checks device specifications
   ├─ Device model: Samsung Galaxy S21 Ultra
   ├─ Screen density: 480 dpi
   └─ Android version: Android 12

Step 3: Android selects appropriate icon file
   ├─ Is device Android 8.0+? YES
   ├─ Use: mipmap-anydpi-v26/ic_launcher.xml (adaptive)
   ├─ Load: ic_launcher_foreground.png (from mipmap-xxhdpi)
   ├─ Apply: Background color #FFFFFF
   └─ Apply: System icon shape (Android decides: circle, rounded square, etc.)

Step 4: Icon displayed on device home screen and app drawer
   └─ User sees beautifully scaled icon that adapts to their device!

🎯 KEY TAKEAWAY:

The Android app icon configuration has THREE COMPONENTS:

1. Configuration
   └─ AndroidManifest.xml tells Android which icon files to use

2. Icon Files
   └─ Organized by screen density in mipmap-* directories
   └─ 5 DPI folders + 1 adaptive folder = 6 directories

3. Adaptive Support
   └─ Android 8+ uses XML to combine image + background color
   └─ Allows system to apply custom shapes

Result: One set of icon files automatically scales to ALL Android devices!
