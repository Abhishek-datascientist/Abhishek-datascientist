The Android app icon is configured in 4 locations:

1. android/app/src/main/AndroidManifest.xml (Configuration)
2. android/app/src/main/res/mipmap-mdpi/ (Low DPI icon files)
3. android/app/src/main/res/mipmap-hdpi/ (High DPI icon files)
4. android/app/src/main/res/mipmap-xhdpi/ (Extra High DPI icon files)
   + mipmap-xxhdpi/ (Extra Extra High DPI)
   + mipmap-xxxhdpi/ (Extra Extra Extra High DPI)
   + mipmap-anydpi-v26/ (Adaptive icon for Android 8+)
   + values/ (Colors for adaptive icon)

STEP-BY-STEP: HOW THE ICON IS CONFIGURED
═══════════════════════════════════════════════════════════════════════

STEP 1: Android Reads Configuration
─────────────────────────────────────

   When Android installs the app, it reads:
   
   android/app/src/main/AndroidManifest.xml
   ┌─────────────────────────────────────────────────────┐
   │ <application                                        │
   │     android:icon="@mipmap/ic_launcher"              │
   │     android:roundIcon="@mipmap/ic_launcher_round"   │
   │ >                                                   │
   └─────────────────────────────────────────────────────┘
   
   This tells Android:
   • Main icon is called "ic_launcher"
   • Round icon is called "ic_launcher_round"
   • Both are in the mipmap directories


STEP 2: Android Checks Device Specifications
──────────────────────────────────────────────

   ┌──────────────────┐
   │  Device Info     │
   ├──────────────────┤
   │ Android Version  │
   │ Screen Density   │
   │ Screen Size      │
   └──────────────────┘
           │
           ▼
   "This is Android 10, 480 dpi device"


STEP 3: Android Selects Appropriate Icon
──────────────────────────────────────────

   Is it Android 8.0 or higher?
   │
   ├─ YES → Use adaptive icon from mipmap-anydpi-v26/
   │        ├─ ic_launcher.xml (tells Android to use)
   │        ├─ ic_launcher_foreground.png (from mipmap-xxhdpi)
   │        └─ Background color #FFFFFF (from values/)
   │        
   │        Result: Android applies system shape
   │        (circle, rounded square, etc.)
   │
   └─ NO → Use regular icon based on DPI
           ├─ 640 dpi? → mipmap-xxxhdpi/ic_launcher.png
           ├─ 480 dpi? → mipmap-xxhdpi/ic_launcher.png
           ├─ 320 dpi? → mipmap-xhdpi/ic_launcher.png
           ├─ 240 dpi? → mipmap-hdpi/ic_launcher.png
           └─ 160 dpi? → mipmap-mdpi/ic_launcher.png


STEP 4: Icon Displayed on Device
─────────────────────────────────

   ┌──────────────────────────┐
   │  App Launcher           │
   │                          │
   │   [App Icon Here]        │ ← Icon displayed!
   │   PocketTracker          │
   │                          │
   └──────────────────────────┘

ICON FILES EXPLAINED
═══════════════════════════════════════════════════════════════════════

Three Different Icon Versions in Each DPI Folder:

1️⃣  ic_launcher.png (Square Icon)
    ┌──────────────────┐
    │                  │
    │   YOUR ICON      │
    │   (Square)       │
    │                  │
    └──────────────────┘
    • Square corners
    • Standard size for that DPI
    • Used on app drawer
    • Used on home screen

2️⃣  ic_launcher_round.png (Rounded Icon)
    ╭──────────────────╮
    │                  │
    │   YOUR ICON      │
    │   (Rounded)      │
    │                  │
    ╰──────────────────╯
    • Rounded corners
    • Same size as ic_launcher.png
    • Used for app shortcuts
    • Used on some device launchers

3️⃣  ic_launcher_foreground.png (Adaptive Icon Image)
    • Larger size (108dp minimum)
    • Used only with Android 8+
    • Combined with background color
    • System applies shape on top
    • Result: Adapts to device icon shape preferences
