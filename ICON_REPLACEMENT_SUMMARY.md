💡 ICON DESIGN BEST PRACTICES
═══════════════════════════════════════════════════════════════════════════════

For future icon updates, follow these guidelines:

1. Source Icon
   • Start with high-resolution source (at least 512×512)
   • Use PNG format with transparency
   • Ensure icon is centered
   • Avoid text that won't be readable at small sizes

2. Android Icons
   • Square icons: Leave padding for all devices to handle
   • Rounded icons: Same as square but with rounded corners
   • Foreground: Make it fill the entire space (9-slice format)
   • Use consistent colors and style across all sizes

3. Web Icons
   • Ensure visibility at small sizes (16×16 favicon)
   • Test in browser tab to verify clarity
   • Use consistent branding across all sizes
   • Support both standard and maskable formats

4. Adaptive Icons (Android 8+)
   • Background: Use solid color or simple pattern
   • Foreground: Icon image on transparent background
   • Safe zone: Keep important elements in center 72dp circle
