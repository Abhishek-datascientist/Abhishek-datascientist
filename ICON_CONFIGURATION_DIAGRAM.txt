4️⃣  ICON FILES BREAKDOWN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Three Types of Icon Files:

A) ic_launcher.png (Square Icon)
   ┌─────────────────────┐
   │                     │
   │   YOUR APP ICON     │
   │   (Square shape)    │
   │                     │
   └─────────────────────┘
   • Used by: Android 7.x and older
   • Shape: Squared corners
   • Used on: App drawer, home screen

B) ic_launcher_round.png (Rounded Icon)
   ╭─────────────────────╮
   │                     │
   │   YOUR APP ICON     │
   │   (Rounded shape)   │
   │                     │
   ╰─────────────────────╯
   • Used by: Android 7.x and older
   • Shape: Rounded corners
   • Used on: App shortcuts, some devices

C) ic_launcher_foreground.png (Adaptive Icon Foreground)
   • Used by: Android 8.0+
   • Size: Larger than regular icons (108dp minimum)
   • Combined with: Background color (#FFFFFF)
   • Result: System applies shape (circle, rounded square, etc.)

6️⃣  SIZE SCALING RATIOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

All icon sizes scale proportionally:

   mdpi (1x)  →  48 px  ────────────────────────── Baseline
    ↓
   hdpi (1.5x) →  72 px  ──────────── 50% larger
    ↓
   xhdpi (2x) →  96 px  ──────────────────── 2x larger
    ↓
   xxhdpi (3x) → 144 px  ──────────────────────────────── 3x larger
    ↓
   xxxhdpi (4x) → 192 px  ──────────────────────────────────────── 4x larger


Adaptive foreground sizes:

   mdpi (1x)  →  108 dp  (72 px at 160 dpi)
    ↓
   hdpi (1.5x) →  162 dp  (108 px at 240 dpi)
    ↓
   xhdpi (2x) →  216 dp  (144 px at 320 dpi)
    ↓
   xxhdpi (3x) → 324 dp  (216 px at 480 dpi)
    ↓
   xxxhdpi (4x) → 432 dp  (288 px at 640 dpi)
